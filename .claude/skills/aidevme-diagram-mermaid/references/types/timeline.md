# timeline

Use when only the order of milestones matters (no durations).

```mermaid
timeline
  accTitle: Release history
  accDescr: Three releases introducing the data model, integrations, and the Copilot agent.
  title Release history
  2026 Q1 : Data model
  2026 Q2 : ERP integration : Service Bus
  2026 Q3 : Copilot Studio agent
```

- `period : event : event`; `section` groups periods.
